## What decides whether a QR code lasts

Every QR code contains text. For a website code, that text is a web address. When someone scans it, their phone reads the address and opens it. So the question is never "does this QR code expire?" but "will the address inside it still work in five years?"

| What's inside the code            | Example                       | Can you change where it goes? | What can stop it                                                                                         |
| --------------------------------- | ----------------------------- | ----------------------------- | -------------------------------------------------------------------------------------------------------- |
| Your own page (static code)       | yourcafe.com/menu             | No, but you can edit the page | Your website or domain going away                                                                        |
| Your own redirect (static code)   | yourcafe.com/qr               | Yes, on your website          | Your website or domain going away                                                                        |
| A QR company's link (dynamic)     | scst.one/abc123               | Yes, in your account          | The company switching it off (trial ended, plan lapsed, scan limit), shutting down, or you deleting it |
| Plain text, WiFi, contact details | WIFI:S:Cafe;P:password;;      | No                            | Nothing. The details live in the pattern, though they go stale if your password or number changes       |

You can tell which kind you have by scanning it and reading the address your phone shows before you tap. If it's your own website, nobody else can switch it off. If it's a short link on another company's domain, the code depends on that company.

## Three ways to make a permanent QR code

### 1. A static code to a page you own

This is the simplest and the most durable. Put the page's address straight into the pattern with a static generator. There is no account and no company in between, so there is nothing to cancel.

The catch is that a printed static code can't be pointed somewhere else. You can still change what's on the page, though. If your menu lives at yourcafe.com/menu and you edit that page, the same printed code shows the new menu. That covers most restaurants, shops and events.

Our [free QR code generator](/qr-code-generator) makes static codes with no account, no trial and no watermark, and you can download PNG or SVG.

### 2. A static code to a redirect on your own domain

If you have a website and want to change the destination later, make a short address on your own site, like yourcafe.com/qr, and point it wherever you want using your website's redirect settings. Most website builders and hosts have one. Then put yourcafe.com/qr in a static code.

You get an editable code with no QR company involved. You don't get scan counts unless your website analytics records visits to that address. And the code only lasts as long as you keep renewing the domain, so set it to auto-renew.

### 3. A dynamic code from a company that won't switch it off

A dynamic code holds the company's short link, so you can edit it and count scans without touching your website. Whether it's permanent depends entirely on that company's policy, not on the code.

Many companies switch dynamic codes off when a free trial ends or a plan lapses. QR Code Generator, for example, says dynamic codes made during its 14-day free trial are [deactivated when the trial ends](https://support.qr-code-generator.com/hc/en-us/articles/7665013224205-I-received-a-message-saying-that-my-QR-Codes-will-be-deactivated-What-does-that-mean). Before you print one, find the answer to three questions in the company's own help pages or terms:

1. What happens to my codes when the trial ends?
2. What happens if I cancel or stop paying?
3. Is there a scan limit, and what happens when I reach it?

## Before you print

- **Scan it with two phones** and check it opens the right page.
- **Use a page you control.** A link to a file on a shared drive or a social post can break if the file is replaced or the post is deleted.
- **Avoid long, messy addresses** in static codes. Longer addresses make denser patterns that are harder to scan when printed small.
- **Make dynamic codes under a shared work email**, not one person's personal account, so the code doesn't go with them when they leave.
- **Use SVG for print.** It stays sharp at any size.
- **Keep good contrast**: dark code on a light background, with a clear margin around it.

## Common questions

### Are free QR codes permanent?

Free static QR codes are, because the address is stored in the pattern and no company can switch it off. Free dynamic codes depend on the company: many stop at the end of a trial. Scanstone's free dynamic codes have no time limit.

### Can a permanent QR code be edited?

A static code can't be repointed after printing, but you can change the page it opens. For a code you can repoint, use a redirect on your own domain or a dynamic code from a company that keeps codes running when you stop paying.

### Do QR codes expire?

The pattern never expires. A code stops working when the address inside it stops working, for example when a QR company deactivates its short link after a trial or a website is taken down.

### How long does a QR code last?

As long as the address inside it keeps working and the print stays readable. A static code to a website you keep online can work for decades.
